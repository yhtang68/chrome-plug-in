# Chrome Plug-in Collection

Small Chrome extension experiments, each kept in its own folder with setup notes.

## Extensions

- [Gmail Hover Sender](Chrome-Plug-In-Gmail-Sender/README.md) - highlights Gmail sender addresses and lets you click a sender to search messages from that address.
- [Markdown Folding Viewer](Md-Folding-Viewer/README.md) - renders opened Markdown files with foldable sections and a floating controls menu for easier navigation.
